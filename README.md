# FeedbackPulse v2

Lightweight SaaS for collecting and analyzing user feedback.

## Features (planned)
- User authentication and project management
- Embeddable feedback widget (floating button)
- Feedback collection API with rate limiting
- Analytics dashboard with charts

## Tech Stack
- Next.js 14 (App Router) with TypeScript
- Supabase for auth and database
- Tailwind CSS for styling
- Vitest for testing
- Recharts for data visualization

## Getting Started

```bash
npm install
npm run dev
```
