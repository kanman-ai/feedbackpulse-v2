FeedbackPulse Widget Demo

This page demonstrates the FeedbackPulse widget in different configurations. The widget appears as a floating button in the bottom-right corner of each demo area.

Note: This is a demo page showing how the widget would appear on a real website. In production, the widget would be loaded from your FeedbackPulse dashboard and connected to your project.

How to Use

To add the FeedbackPulse widget to your website, simply include this script tag:

<script src='https://feedbackpulse.com/widget.js?project_id=YOUR_PROJECT_ID&theme=#3B82F6&question=How%20can%20we%20improve%3F'></script>

Parameters:

  • project_id (required): Your project ID from FeedbackPulse
  • theme (optional): Hex color code for the widget theme (default: #3B82F6)
  • question (optional): Custom question text (default: "How can we improve?")
  • position (optional): Widget position - bottom-right, bottom-left, top-right, top-left (default: bottom-right)

Widget Features

  • Shadow DOM Isolation: Widget styles won't conflict with your site
  • Responsive Design: Works on desktop and mobile devices
  • Customizable Theme: Match your brand colors
  • Star Ratings: 1-5 star rating system
  • Comment System: Collect detailed feedback
  • Email Collection: Optional email capture
  • Error Handling: Graceful fallbacks if loading fails

Browser Support

The widget supports all modern browsers including:

  • Chrome 63+
  • Firefox 63+
  • Safari 13+
  • Edge 79+

Privacy & Security

  • Widget loads asynchronously without blocking your page
  • All data is transmitted securely via HTTPS
  • Minimal data collection - only what users explicitly provide
  • Compliant with GDPR and privacy regulations
